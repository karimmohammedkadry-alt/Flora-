تقرير فصل لوحة التحكم - النسخة 7

- شاشة Loading مستقلة مع انتقال للرئيسية.
- لا توجد صفحة Login ضمن مسار الداشبورد.
- صفحات مستقلة: overview, products, orders, messages, account.
- ملفات CSS وJS مستقلة لكل صفحة مع ملفات مشتركة للوظائف العامة فقط.
- صفحة المنتجات تدعم وضعًا محليًا للتجربة بدون جلسة؛ الحفظ المحلي لا يغيّر بيانات الموقع المنشور.
- الطلبات والرسائل لا يتم عرضها بدون صلاحية خادم.
- لم يتم تعطيل RLS أو توسيع صلاحيات Edge Function.
- تم إجراء فحوصات صياغة ومسارات ثابتة بعد إنشاء الحزمة؛ لم يتم اختبار نشر حي أو الاتصال بقاعدة البيانات الفعلية.
