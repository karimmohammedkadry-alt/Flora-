لوحة تحكم Flora - هيكل مفصول

- html/: صفحة مستقلة لكل قسم.
- css/: common.css للتنسيقات العامة، وملف CSS لكل صفحة.
- js/: admin-common.js للوظائف المشتركة، وملف JS مستقل لكل صفحة.
- images/: صور خاصة بالداشبورد؛ شعار المتجر موجود في Store/frontend/images.
- backend/: وصف مكان الخدمات الخلفية؛ الكود الفعلي في Backend/supabase وBackend/firebase.

بدون جلسة إدارة: يمكن فتح الواجهة مباشرة. صفحة المنتجات تدعم وضع تعديل محلي يحفظ التغييرات في هذا المتصفح فقط، ولا يغير المتجر المنشور. الطلبات ورسائل العملاء تبقى خاصة.
